# 데이터 거버넌스

## 기본 정책

1. 외부 데이터의 접근 가능성과 재사용 가능성을 구분한다.
2. 권리 상태가 불명확하면 수집·커밋·재배포를 기본적으로 중단한다.
3. 코드 라이선스가 API 응답이나 코퍼스 콘텐츠에 적용된다고 추정하지 않는다.
4. 원본과 파생물 모두 소스 매니페스트로 추적한다.
5. 필요한 최소 범위만 수집하고 원격 서비스의 이용 조건과 속도 제한을 따른다.

## 저장 등급

| 등급 | 예 | Git 커밋 | 재배포 |
|---|---|---:|---:|
| A: 프로젝트 자체 자료 | 스키마, 코드, 합성 예시 | 허용 | Apache-2.0 |
| B: 명시적 공개 데이터 | 조건이 확인된 코퍼스 릴리스 | 검토 후 | 원 라이선스 준수 |
| C: 제한/조건부 자료 | 개별 인용 허용, 대량 복제 제한 | 금지 | 금지 또는 허가 필요 |
| D: 권리 불명 | 출처 불명 이미지, 비공식 덤프 | 금지 | 금지 |

## 디렉터리 규칙

- `data/raw/`: 변경하지 않은 획득물. 기본적으로 Git에서 제외한다.
- `data/interim/`: 파싱·정규화 중간물. 재생성 가능해야 하며 Git에서 제외한다.
- `data/processed/`: 검색·그래프 입력. 공개 가능한 샘플만 별도 검토 후 커밋한다.
- `data/manifests/`: 데이터 자체가 아니라 출처·권리·획득 계보를 기록한다.

## 매니페스트 검토

새 소스를 활성화하려면 다음 필드가 완성되어야 한다.

- 공식 소스와 담당 기관
- 자료 유형별 라이선스 근거 URL
- 요구되는 인용문
- 대량 접근·캐시·변형·재배포 허용 상태
- 획득 방법, 버전, 시각, 체크섬
- 삭제/갱신 방법과 담당 이슈

허용 상태는 `allowed`, `restricted`, `unknown` 중 하나로 명시한다. 빈 값은 허용으로 해석하지 않는다.

## 출처 계보

모든 파생 레코드는 다음 연결을 유지한다.

```text
derived record
  → transformation run + code version
  → raw object checksum
  → acquisition event
  → source manifest
  → official source and license evidence
```

한 원본에서 파생된 임베딩과 그래프 관계도 삭제 대상에서 제외되지 않는다.

## 조건 변경과 삭제

소스의 조건이 바뀌거나 권리자가 삭제를 요청하면:

1. 해당 매니페스트를 `suspended`로 바꿔 신규 수집을 중단한다.
2. 계보 그래프로 원본·파생 레코드·인덱스 항목을 식별한다.
3. 공개 배포물과 캐시에서 제거하거나 접근을 차단한다.
4. 삭제 범위와 시각을 남기되 제한된 콘텐츠 자체는 로그에 복제하지 않는다.
5. 영향을 받은 Context Package를 무효화하거나 재생성 대상으로 표시한다.

## 개인정보와 민감정보

고대 자료가 주 대상이지만 API 계정, 현대 소장자·제보자 정보, 비공개 발굴 위치 등이 포함될 수 있다. 인증정보는 환경 변수나 승인된 비밀 저장소에만 두며, 공개 데이터에서도 현대인의 불필요한 개인정보를 수집하지 않는다.

## AI 및 모델 제공자

외부 모델 API로 텍스트를 전송하기 전 해당 데이터의 제3자 처리 허용 여부와 모델 제공자의 보존·학습 정책을 확인한다. 제한 데이터는 로컬 모델/검색만 사용하거나 권리자의 명시적 허가를 받는다. 모델에 보낸 레코드와 목적도 변환 실행 기록에 남긴다.

## 면책

이 문서는 프로젝트 운영 원칙이며 법률 자문이 아니다. 조건이 모호하거나 충돌하면 배포를 중단하고 데이터 제공 기관 또는 적절한 전문가에게 확인한다.
