# ANE Context AI 학습 경로

ANE Context AI는 고대근동(Ancient Near East)을 단순 연대 암기가 아니라 **질문 → 맥락 → 1차 사료 → 해석 → 논쟁 → 다음 질문**의 순환으로 배우는 프로젝트다.

## 3단계 학습 구조

### 1. ANE 101 — Learn
초보자가 고대근동의 공간·시간·사료·핵심 전환점을 익힌다.

- Module 0: 우리가 고대근동을 어떻게 아는가?
- Module 1: 고대근동은 어디인가?
- Module 2: 5,000년의 시간을 어떻게 볼 것인가?
- Module 3: 도시와 문자는 왜 등장했는가?

완료 기준은 모든 왕조를 외우는 것이 아니라, 실제 1차 사료 하나를 보고 출처가 연결된 첫 Context Package를 만들어보는 것이다.

### 2. Explore — 주제별 탐구
관심 분야를 골라 여러 시대와 지역을 비교한다.

- Origins: 농업·도시·국가의 탄생
- Writing: 문자·행정·지식
- Society: 가족·노동·경제·노예
- Law: 법·재판·계약
- Religion: 신화·신전·점술·기도
- Diplomacy: 국제외교·전쟁·조약
- Empire: 아카드·아시리아·바빌로니아·페르시아
- Daily Life: 평범한 사람들의 삶
- Bible & ANE: 이스라엘·유다와 고대근동
- Collapse: 붕괴·전환·회복

### 3. Research — 실제 사료 기반 연구
연구 질문을 정하고 ORACC, CDLI, eBL, TLA 등 허가된 데이터에서 근거를 모아 Context Package를 만든다.

연구 단계에서는 반드시 다음을 분리한다.

1. 1차 사료가 직접 말하는 내용
2. 현대 연구자의 해석
3. 학계에서 논쟁 중인 주장
4. AI가 제안한 추론
5. 현재 자료로는 판단할 수 없는 부분

## v0.1 성공 기준

완전 초보자가 15~30분 안에 다음을 경험한다.

1. 고대근동의 대략적인 공간을 이해한다.
2. 긴 연대를 큰 흐름으로 파악한다.
3. 우리가 과거를 아는 근거가 무엇인지 이해한다.
4. 도시화와 문자 발생의 관계를 질문한다.
5. 실제 고대 문헌·유물 하나를 본다.
6. AI와 함께 첫 Context Package를 만든다.

이 학습 흐름에서 발생한 초보자 질문은 동시에 검색·RAG 시스템의 평가 질문으로 사용한다.
