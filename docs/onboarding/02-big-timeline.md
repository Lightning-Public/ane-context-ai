# Module 2 — 5,000년의 시간을 어떻게 볼 것인가?

## 핵심 질문
수메르·바빌로니아·아시리아는 어떤 순서와 관계 속에서 이해해야 할까?

초보자 단계에서는 세부 왕명과 정확한 연대를 모두 외우지 않는다. 먼저 큰 전환을 이해한다.

## 큰 흐름
- 농경과 정착
- 도시화
- 초기 문자
- 수메르 도시국가
- 아카드 제국
- 우르 III와 고바빌로니아 세계
- 후기 청동기 국제질서
- 기원전 12세기 전후의 대전환
- 신아시리아 제국
- 신바빌로니아
- 아케메네스 페르시아

## 학습 원칙
날짜보다 먼저 '무엇이 무엇보다 앞섰는가', '어떤 체제가 무엇으로 바뀌었는가'를 이해한다.

고대근동 연대는 지역과 자료에 따라 불확실성과 여러 연대안이 존재할 수 있으므로 ANE Context AI에서는 가능한 경우 다음을 함께 기록한다.

- 원 자료의 날짜 표현
- 정규화된 BCE 범위
- 사용한 chronology system
- 불확실성 또는 학계 논쟁 상태
