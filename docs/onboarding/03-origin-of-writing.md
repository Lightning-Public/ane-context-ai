# Module 3 — 도시와 문자는 왜 등장했는가?

## 핵심 질문
사람들은 왜 문자를 만들었을까?

초기 학습에서는 문자를 문학 작품의 도구로만 보지 않는다. 도시가 커지고 생산·저장·분배·노동을 관리해야 하면서 기록 기술이 어떤 역할을 했는지 살펴본다.

## Context Chain
농업 → 잉여 생산 → 저장 → 분배 → 인구 집중 → 행정 복잡성 → 기록 필요 → 초기 문자

이 연결은 단순한 단일 원인 설명이 아니라 탐구를 위한 가설 구조다. 실제 자료에서는 지역·시기·문서 유형별 차이를 확인해야 한다.

## 첫 Primary Source 경험
초보자는 실제 초기 행정 점토판 또는 원시 설형문자(proto-cuneiform) 자료 하나를 본다.

화면 또는 Context Package는 최소한 다음을 함께 제시한다.

- 유물/문헌 식별자
- 출토지 또는 알려진 소장 맥락
- 대략적 연대와 연대 체계
- 이미지 링크(권리 조건을 준수할 때)
- 전사 또는 기호 정보
- 현대 연구자가 제안한 해석
- 이 자료로 말할 수 있는 것과 말할 수 없는 것

## 학습 질문
1. 가장 초기 기록은 무엇을 세고 분류했는가?
2. 기록이 없다면 큰 도시의 생산과 분배를 어떻게 관리했을까?
3. 초기 문자를 '발명'이라고 부를 때 단일 사건으로 이해해도 되는가?
4. 문자가 행정에서 문학·법·외교·학문으로 확장되는 과정은 어떻게 달랐는가?

## Context Package 실습
질문: `왜 문자가 탄생했는가?`

AI는 다음 순서로 답을 구성한다.

1. 질문과 용어를 정규화한다.
2. 시기와 지역 범위를 명시한다.
3. 실제 초기 자료를 검색한다.
4. 서로 다른 문헌 유형과 고고학 맥락을 비교한다.
5. 직접 증거와 현대 해석을 분리한다.
6. 경쟁 가설과 불확실성을 남긴다.
7. 모든 핵심 주장에 출처를 연결한다.

이 모듈은 Research R002와 같은 질문을 사용하여 학습 UX와 검색/RAG 시스템을 동시에 평가한다.
